# Script It! — downloads and bug reports

Script It! is a lined-script tool for Adobe Premiere Pro. This repository is the public home for installer releases and bug reports; the application source code is private and proprietary.

**Downloads are not available yet.** The combined Mac/Windows installer is undergoing testing. No release or installer asset has been published here.

[Product details and installation guide](https://www.whatever-industries.com/p/script-it.html) · [Report a bug](https://github.com/whatever-industries/script-it/issues/new/choose)

## Reporting a problem

Please include the Script It! version, Premiere version, operating system and steps that reproduce the issue. If the plugin offers **Copy error details**, paste the report after checking it for private information.

Issues and attachments are public. Do not upload private scripts, client footage, project files, payment information, activation credentials or unredacted personal paths. Describe the media type instead, or contact **whatev.indus@gmail.com** if a private example is needed.

## Installer status

The planned single `.ccx` contains builds for Mac Apple Silicon, Mac Intel and Windows x64. Build availability does not establish Premiere runtime compatibility. Tested platforms and known limitations will be listed in each release's notes. Premiere Pro 26.5 or later and Creative Cloud desktop are required; Premiere 27 compatibility is not yet qualified.

Installation uses Adobe Creative Cloud's standard installer. Keep operating-system security protections enabled. The product page contains installation guidance and troubleshooting.

## Future releases

Approved releases will contain `Script-It.ccx`, `SHA256SUMS.txt` and release notes. This repository does not automatically publish builds from the private source repository. A release will only be published after testing and approval.
